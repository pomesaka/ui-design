# 画面の組み立て方

人間中心設計とユーザビリティの定番の原則(ヒューリスティック)に従う。視覚的なまとまりはゲシュタルトの原則で考え、値は[token](../themes/README.md)、部品の選択は[部品の一覧](../components/README.md)に従う。以下は、それらに加えてこのrepositoryで重視することと決めたこと。既定から外れるときは、利用者・内容・操作の違いで理由を説明する。

## 利用者から始める

配置や見た目より先に、誰が・どんな状況で・何を期待し・何をしに来て・見た後にどう動くかを利用者ごとに書き出し、優先する人を決める。書き出したことは根拠のある事実と推測による仮定を分け、仮定に頼る判断は確かめる方法か直しやすい形を選ぶ。

画面と各案は次の三つで評価する。

1. **叶えられるか。** 各利用者の期待と目的に、この画面で届くか。
2. **阻害していないか。** 優先する人の目的を、他の情報・操作・装飾が邪魔していないか。
3. **迷わないか。** 次に何をすればよいか、操作した結果がどうなったかが分かるか。

## 進め方

1. 利用者のストーリーを書き、優先する人の主な目的から主操作を一つ決める。決まらなければ画面を分ける。
2. 情報と操作を実際に近いデータで書き出し、重要度と頻度で配置の強さを決める。最長の文字列・0件・大量の件数も用意する。
3. 方向の違う構造の案を2〜3出し、三つの問いで比べて選んだ理由を残す。最初の案はありがちな形になりやすい。
4. 部品とtokenで組み、起こる状態(初回読み込み・空・失敗・更新失敗・権限なし・処理中)を作る。
5. [確認](#確認)し、利用者の目的に要らない要素を削る。

## このrepositoryの決定

- 強弱は位置 → 余白 → 文字 → 色の順で付ける。主操作(`primary`)はページ・Dialog等の一つの操作領域に一つ。
- 文字の段は、ページ見出し`font-heading text-heading`、区画見出し`font-heading text-reading`、本文`font-body text-body`、補足`font-control text-caption text-reading-secondary`に限る。labelと操作の文字は部品に任せる。
- 余白はtokenの段(`1`・`2`・`3`・`4`・`6`・`8`・`12`、`panel`・`reading`)から選ぶ。段外の値と任意値は検査で落ちる。既定は次のとおり。

| 関係 | 既定 |
| --- | --- |
| 同じグループの項目、見出しと補足 | `gap-1`〜`gap-3` |
| 区画見出しと中身、グループ間 | `gap-4`〜`gap-6` |
| ページ直下の区画間 | `gap-12` |
| 一覧の行 | 区切り線と`py-3`。行の操作は`size="sm"` |
| 本文の幅 | 業務画面は`max-w-5xl`〜`max-w-6xl`、文章が主なら`max-w-prose` |

- 区切りは余白 → 区切り線 → 面の順に検討する。一覧の行は区切り線で分ける。カード(面)は一つの対象を選ぶ・比べるときに使い、入れ子にしない。Banner・Notice等の部品が持つ面はこの判断に含めない。影はpopupとDialogだけが持つ。
- `primary`と状態色(`success`・`warning`・`destructive`・`info`)は意味があるときだけ使い、面積の大半は`background`・`card`・`foreground`にする。
- 結果は時間で消える表示で伝えない。[結果の伝え方](../components/README.md#結果の伝え方)に従う。
- 背景も枠もないボタン(`ghost`)は、iconボタン・Dialogの閉じる・ツールバー等、形や場所でボタンと分かるときだけ使う。一覧や本文の文字だけの操作は`outline`系にする。
- 一覧は`List`で組む。行の操作は二つまで見せて残りは`Menu`へ入れ、行を消した後は次の行の同じ操作へfocusを移す。
- ボタンは結果を表す動詞で書き、日本語UIに英字の飾りlabelを混ぜない。

## 避けるもの

生成されたUIに出やすく、内容を支えない表現。理由を説明できない限り使わない。

- すべての区画をカードで囲む、同じ形のカード(icon・見出し・文)を並べただけの構成
- 大きな数字と小さなlabelを並べただけの指標欄
- グラデーション、グラデーションの文字、色付きの太い左線、装飾目的のぼかし・ガラス
- 見出しの上の小さな英字label、`01`・`02`の番号飾り、見出しの一語だけの色付け、見出しを言い換えただけの説明文
- 絵文字や文字記号をiconの代わりにすること
- 中央揃えの多用、区画ごとに違う余白
- 必要のないmodal、hoverでしか見えない操作

## 確認

描画して確かめる。文書を読んだことや見本があることを確認の代わりにしない。

- 書き出した利用者ごとに、画面を開いてから目的を終えるまでを辿り、三つの問いに答える。
- 幅390px・768px・1280px以上で、明暗の両テーマを撮って見る。文字200%、長い文字列・0件・大量の件数でも崩れないか。
- keyboardだけで主操作まで届き、focusが見え、Dialogを閉じた後に元の場所へ戻るか。reduced motionで同じ結果に届くか。
- [避けるもの](#避けるもの)に当たるものがないか。
