# ui-design

複数のプロジェクトで使えるデザインの部品と知識を育てるためのリポジトリ。
対象はデザイントークン、質感・モーションを含むコンポーネント、エージェント用スキルと、それらを触って確かめるカタログ。
部品はReact・Tailwind CSS v4・Base UIで作り、採用先へ複製して使う。
